Suit Purge is now hidden

The maze shooter used to sit in the nav under “Play.” It doesn’t anymore — the section ships with the hidden attribute and the link is gone. This is what replaced it, how a visitor finds it, and what changed in the code to make that safe.

Why bother hiding it

A linked nav item is furniture. A hidden one is a find. Suit Purge was built to be a surprise inside a music site — a raycaster shooter aimed at politicians, billionaires, trillionaires and “high command” — and a top-nav “Play” tab flattened that into just another page. Removing the link doesn’t remove the game; it moves the discovery from a click to a small ritual, which is closer to what an easter egg is supposed to feel like.

What happens on unlock

One reveal path, however you triggered it

Section unhides

The hidden attribute drops and a 0.9s fade-and-rise plays once.

Canvas resizes

A synthetic resize event fires so the game rebuilds its render buffers — while hidden, the canvas had no real box to size against.

Session remembers

A flag goes into sessionStorage. A mid-session refresh keeps the maze unlocked without re-entering anything.

Page scrolls in

Every path except a restored session smooth-scrolls to the section and focuses the play button.

Guardrails
  • Form-safe. Typed-word matching ignores keystrokes inside inputs, textareas, and contenteditable elements — Contact is untouched.
  • Idempotent. Re-triggering an already-unlocked egg just re-scrolls; it won't re-animate or double-fire the resize event.
  • No content changed. Same game, same four enemy archetypes, same wave logic — only the entry point moved.
